### Назначение Event Tracking
Event Tracking — это инструмент для отладки с заметками. Вы строите путь (цепочку) из шагов, и в каждом шаге пишете заметку (комментарий), поясняющую, что и зачем отслеживается. В результате формируется полный путь с пояснениями, который сохраняется (например, в json). Это позволяет:
- Воспроизводить сложные сценарии отладки и анализа
- Быстро возвращаться к нужным последовательностям действий
- Не выискивать заново, как что работает — вся логика и ваши комментарии всегда под рукой
- Использовать путь и заметки как живую документацию по архитектуре и поведению системы

Путь и заметки — это единое целое для отладки, анализа и документации.

## Актуализация

- **Система хранения данных:**
  - Все пути и шаги Event Tracking теперь сериализуются в JSON (`ProjectSettings/ArchitectureVisualizer.paths.json`).
  - Для интеграции с ИИ используется отдельный файл `ProjectSettings/ArchitectureVisualizer.ai.json` с инструкцией и примером формата.
  - При принятии пути из AI-файла он автоматически переносится в основной файл и удаляется из AI-файла.
- **Архитектура:**
  - Класс `EventTrackingManager` теперь поддерживает работу с двумя файлами: основной и AI.
  - Добавлен метод `AcceptAiPath`, реализующий перенос пути из AI-файла в основной.
  - В окне Event Tracking реализовано отображение и принятие AI-путей.
- **UI/UX:**
  - Пути из AI-файла выделяются цветом и помечаются как "AI Suggestion".
  - Кнопка "✔ Принять" для быстрого переноса пути в основной json.
- **Безопасность и переносимость:**
  - Все данные Event Tracking теперь хранятся в git-репозитории проекта.
  - EditorPrefs полностью удалён из логики хранения путей/шагов.
- **Рекомендации по использованию:**
  - Для добавления новых путей через ИИ или вручную используйте `ArchitectureVisualizer.ai.json` (см. инструкцию внутри файла).
  - Для принятия изменений используйте кнопку в UI плагина.
- При первом запуске плагина автоматически создаётся текстовая инструкция `ArchitectureVisualizer.ai.instructions.txt` с описанием формата AI json и примерами.
- Для интеграции с ИИ и ручного редактирования используйте только массив `items` в AI json, а все пояснения и примеры — в инструкции.
- Теперь для подгрузки новых AI-путей достаточно нажать кнопку "Analyze Project" — оба json-файла перечитываются с диска, и все изменения сразу видны в UI.
