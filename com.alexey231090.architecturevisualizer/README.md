# Architecture Visualizer

Плагин для Unity, который помогает визуализировать и анализировать зависимости между скриптами в вашем проекте, а также удобно отлаживать логику с помощью системы Event Tracking и заметок.

## Новое в версии (июнь 2024)

- **Система хранения путей и шагов Event Tracking полностью переведена на JSON-файлы.**
  - Все пользовательские цепочки и шаги теперь сохраняются в `ProjectSettings/ArchitectureVisualizer.paths.json`, который входит в git-репозиторий проекта.
  - Для интеграции с ИИ добавлен второй файл `ProjectSettings/ArchitectureVisualizer.ai.json`. В этот файл можно добавлять предложения новых путей и шагов (например, сгенерированные ИИ или коллегами).
  - В плагине реализована возможность принять путь из AI-файла одной кнопкой — он переносится в основной файл и исчезает из AI-блока.
  - **Теперь при первой установке плагина в папке ProjectSettings автоматически создаются:**
    - `ArchitectureVisualizer.paths.json` — основной файл путей.
    - `ArchitectureVisualizer.ai.json` — файл для предложений от ИИ и коллег.
    - `ArchitectureVisualizer.ai.instructions.txt` — подробная инструкция по формату AI json для ручного редактирования и интеграции с ИИ.
- **AI-интеграция:**
  - Для добавления новых путей через ИИ или вручную используйте только массив `items` в файле `ArchitectureVisualizer.ai.json`. Инструкция и примеры — в соседнем `.txt`-файле.
  - Все предложения от ИИ отображаются в плагине с пометкой "AI Suggestion" и отдельным цветом.
- **EditorPrefs больше не используется.** Все данные хранятся только в JSON, что гарантирует переносимость, версионирование и безопасность.
- **UI/UX:**  
  - Добавлена кнопка "✔ Принять" для путей из AI-файла.
  - Пути из AI-файла визуально выделяются.
- **Документация и структура проекта обновлены.**

## Установка

1. Откройте ваш Unity проект
2. В Package Manager выберите "Add package from git URL"
3. Введите URL: `https://github.com/alexey231090/ArchitectureVisualizer.git`
4. Нажмите "Add"

## Структура плагина

```
com.alexey231090.architecturevisualizer/
├── Editor/
│   └── ArchitectureVisualizer/
│       ├── Core/           # Основные компоненты плагина
│       ├── Modules/        # Модули плагина
│       └── Resources/      # Ресурсы модулей
├── package.json           # Конфигурация пакета
└── README.md             # Документация
```

## Использование

1. В Unity выберите Tools > Architecture Visualizer
2. Откроется окно с вкладками:
   - Dependencies: Графическое представление зависимостей
   - Structure: Иерархическая структура зависимостей
   - Analysis: Детальный анализ зависимостей
   - Event Tracking: управление цепочками, шагами, отслеживанием переменных и заметками (с поддержкой кириллицы и многострочных комментариев)

## Работа с AI-файлом

- Для интеграции с ИИ или совместной работы используйте файл `ProjectSettings/ArchitectureVisualizer.ai.json`.
- Внутри файла есть подробная инструкция и пример структуры.
- Вы (или ИИ) можете добавлять новые пути и шаги в массив `paths`.
- В плагине эти предложения отображаются с пометкой "AI Suggestion" и отдельным цветом.
- Для принятия предложения нажмите кнопку "✔ Принять" — путь будет перенесён в основной файл и исчезнет из AI-блока.

## Функции

- Визуализация зависимостей между скриптами
- Анализ циклических зависимостей
- Поиск неиспользуемых скриптов
- Группировка скриптов по папкам
- Экспорт данных в различные форматы
- Удобная отладка с помощью Event Tracking (см. выше)
- Интеграция с ИИ для генерации и приёма новых путей

## Требования

- Unity 2020.3 или выше
- .NET 4.7.1 или выше
