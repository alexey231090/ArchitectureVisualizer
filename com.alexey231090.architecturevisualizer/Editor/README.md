# Architecture Visualizer

Плагин для Unity, который помогает визуализировать архитектуру проекта и управлять отладочными логами.

## Debug Logs (новое)

- Добавление нескольких скриптов для анализа логов.
- Для каждого скрипта отображаются все Debug.Log/Debug.LogWarning/Debug.LogError.
- Управление логами прямо из UI (включение/отключение).
- Поддержка кириллицы и автоматическая перекодировка.

## Event Tracking

- Система для создания, редактирования и отслеживания цепочек событий и переменных.
- Многострочные комментарии, поддержка кириллицы, массивов, коллекций, множественных экземпляров.

## Установка и требования

- Unity 2020.3 или выше
- .NET 4.7.1 или выше

## Использование

1. В Unity выберите Tools > Architecture Visualizer
2. Откройте нужную вкладку:
   - **Debug Logs** — управление логами
   - **Event Tracking** — работа с цепочками событий
