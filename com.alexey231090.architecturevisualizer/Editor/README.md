# Architecture Visualizer

> ⚠️ ВНИМАНИЕ: Плагин меняет направление! Теперь основной фокус — отладка с заметками (Event Tracking). Таблицы зависимостей и Script Details считаются устаревшими и будут убраны в будущих версиях. Пока они доступны, но не развиваются. Ничего не удалять без отдельной команды: сначала только комментировать и тестировать!

Плагин для Unity, который помогает визуализировать и анализировать зависимости между скриптами, а теперь — в первую очередь, отлаживать проект с помощью системы Event Tracking и заметок.

## Event Tracking (новое)

- Добавление и редактирование цепочек (paths) и шагов (steps)
- Выбор скрипта и переменной для каждого шага (поддержка вложенных, коллекций, словарей)
- Многострочные комментарии
- Английский интерфейс
- Поддержка кириллицы (работает "из коробки")
- Поддержка массивов, коллекций, множественных экземпляров объектов
- Подсветка изменений (fade/highlight)
- Реальное время обновления значений

### Для чего нужен Event Tracking?

Event Tracking — это инструмент для отладки с заметками. Вы строите путь (цепочку) из шагов, и в каждом шаге пишете заметку (комментарий), поясняющую, что и зачем отслеживается. В результате формируется полный путь с пояснениями, который сохраняется (например, в json). Это позволяет:
- Воспроизводить сложные сценарии отладки и анализа
- Быстро возвращаться к нужным последовательностям действий
- Не выискивать заново, как что работает — вся логика и ваши комментарии всегда под рукой
- Использовать путь и заметки как живую документацию по архитектуре и поведению системы

Путь и заметки — это единое целое для отладки, анализа и документации.

## Установка

1. Откройте ваш Unity проект
2. В Package Manager выберите "Add package from git URL"
3. Введите URL: `https://github.com/alexey231090/ArchitectureVisualizer.git`
4. Нажмите "Add"

```

    │   └── Resources/      # Ресурсы модулей

    └── package.json
```

## Использование

1. В Unity выберите Tools > Architecture Visualizer
2. Откроется окно с вкладками:
   - Event Tracking: управление цепочками и шагами, отслеживание переменных, заметки
   - (Устаревшие) Tables: таблицы с различными типами зависимостей
   - (Устаревшие) Script Details: детальная информация о скриптах и их полях

## Features

- **Event Tracking:** добавление/редактирование цепочек и шагов, поддержка множественных экземпляров, массивов, коллекций, словарей, многострочных комментариев, английский UI, поддержка кириллицы
- (Устаревшее) Анализ и отображение зависимостей между скриптами
- (Устаревшее) Просмотр структуры проекта
- (Устаревшее) Детальный анализ полей скриптов
- (Устаревшее) Отображение текущих значений полей
- (Устаревшее) Поддержка вложенных типов
- (Устаревшее) Отображение значений массивов и коллекций
- (Устаревшее) Группировка скриптов по папкам
- (Устаревшее) Анализ использования компонентов

## Known Issues

- В некоторых версиях Unity на Windows возможны проблемы с вводом русского текста в TextField (см. PROGRESS.md). В новой версии поддержка кириллицы работает без костылей.
- Подсветка изменений и реальное время обновления значений Event Tracking — реализованы.
- (Устаревшее) Возможны проблемы с таблицами зависимостей и Script Details — эти функции будут удалены.
